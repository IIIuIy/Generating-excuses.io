# Генератор оправданий

Игра-оракул: настраиваешь «правдоподобность» и получаешь случайное оправдание — от абсурдного до вполне веского. Внешних зависимостей и сервера нет: достаточно открыть `index.html`.

## Запуск

Откройте `index.html` в браузере. Сборка не нужна: `styles.css`, `logic.js` и `app.js` подключаются напрямую.

Тесты логики запускаются через Node.js:

```
node --test tests/logic.test.js
```

## Файлы

- `index.html` — разметка и структура экранов;
- `styles.css` — темы, адаптив, анимации оракула;
- `logic.js` — чистая логика: тиры, база из 456 оправданий, генерация, поиск, «оправдание дня», статистика;
- `app.js` — интерфейс, localStorage, звук, клавиатура, тосты;
- `tests/logic.test.js` — автоматические тесты (`node:test`, 8 тестов);
- `CHANGELOG.md` — история версий.

## Как играть

1. Двигай ползунок **«Правдоподобность»** (1–100) — от «Абсурда» до «Веского», или нажми **🎲 Случайно**.
2. При желании включи **«Подробную версию»** — к оправданию добавится случайная деталь.
3. Нажми на оракула **✨** (или пробел) — через короткую паузу появится результат.
4. Кнопки под результатом: **копировать**, **в избранное**, **поделиться**, **ещё** (быстрый повтор с теми же настройками).

### Тиры

| Правдоподобность | Тир | Пример |
|---|---|---|
| 1–29 | 🌀 Абсурд | «Меня задержал говорящий голубь…» |
| 30–49 | 👽 Странное | «Сломался лифт, и я прошёл 12 этажей…» |
| 50–69 | 🤔 Правдоподобное | «Задержался на работе: созвонились с клиентом» |
| 70–100 | ✅ Веское | «Срочный созвон затянулся на час» |

В базе **456 уникальных оправданий**: по 114 на каждый тир (14 исходных + 400 новых). Генератор не повторяет последние 8 результатов. «Оправдание дня» выбирается детерминированно по дате — оно одинаково у всех и обновляется каждый день.

## История, избранное и статистика

Правая колонка содержит четыре вкладки:

- **История** — последние 30 результатов (клик по записи открывает её снова);
- **Избранное** — до 50 сохранённых оправданий;
- **База** — поиск по всем 456 оправданиям (например: «голубь», «сервер», «пробки»); результат можно открыть как текущий;
- **Статистика** — всего создано, распределение по тирам, размеры истории и избранного.

Кнопка «Очистить раздел» очищает активную вкладку.

## Управление с клавиатуры

| Клавиша | Действие |
|---|---|
| `Пробел` / `Enter` | Сгенерировать оправдание |
| `C` / `Ц` | Скопировать результат |
| `F` / `А` | Добавить/убрать из избранного |
| `R` / `К` | Случайная правдоподобность |
| `T` / `Е` | Переключить тему |
| `Esc` | Скрыть результат |

## Данные и техника

- Настройки, история, избранное и статистика хранятся в `localStorage` под ключом `excuse_gen_v1` и восстанавливаются при загрузке; битые/устаревшие значения санитизируются.
- Две темы: **бежевая** (светлая) и **ночная** (тёмная, глубокий синий) — `data-theme` на `<html>`, переключаются кнопкой и клавишей `T`. Логотип из шапки удалён.
- Звук синтезируется через WebAudio (без файлов), включается/выключается кнопкой 🔊 и запоминается; полный откат при отсутствии WebAudio.
- Кнопка «Поделиться» использует Web Share API, а если он недоступен — копирует текст.
- Учитывается `prefers-reduced-motion`: анимации оракула и появления результата отключаются.
- Интерфейс доступен с клавиатуры: у ползунка, кнопок и вкладок есть подписи, результат и тосты объявлены через `aria-live`.
